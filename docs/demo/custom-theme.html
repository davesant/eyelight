Custom theme

This page restyles Minisearch to match a warm, bookish site. The idle hint is on the left, and the prompt says "find". Type reed or bend to see it.

How it's done

The component lives in a shadow root, so none of the site's styles can break it. Instead, it exposes CSS custom properties, parts and highlight names. This page uses all three:

minisearch-ui {
  --ms-bg: #fffaf0;  --ms-fg: #2b2118;  --ms-accent: #a4410e;
  --ms-radius: 2px;  --ms-font: Georgia, serif;
  --ms-shadow: 6px 6px 0 #2b2118;
}
minisearch-ui::part(hint) { border-width: 2px; font-style: italic; }
::highlight(minisearch)         { background-color: #c7f0d8; color: #000; }
::highlight(minisearch-current) { background-color: #1a7f4b; color: #fff; }

The script tag sets the prompt and position:

<script src="minisearch.min.js" defer data-prompt="find" data-position="left"></script>
