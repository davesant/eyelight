This is a made-up demo site for trying Minimarker. Type anywhere, for example reed, bend or tuning.

Custom theme

This page restyles Minimarker to match a warm, bookish site, and switches every default: the bar is centred, suggestions show as you type, the cursor is a thin line and matches get flat highlight colours. The prompt says "find". Type reed or bend to see it.

How it's done

The component lives in a shadow root, so none of the site's styles can break it. Instead, it exposes CSS custom properties, parts and highlight names. This page uses all three:

minimarker-ui {
  --minimarker-bg: #fffaf0;  --minimarker-fg: #2b2118;  --minimarker-accent: #a4410e;
  --minimarker-radius: 2px;  --minimarker-font: Georgia, serif;
  --minimarker-shadow: 6px 6px 0 #2b2118;
}
minimarker-ui::part(hint) { border-width: 2px; font-style: italic; }
::highlight(minimarker)         { background-color: #c7f0d8; color: #000; }
::highlight(minimarker-current) { background-color: #1a7f4b; color: #fff; }

The script tag sets the prompt and switches the defaults:

<script src="minimarker.min.js" defer data-prompt="find" data-position="center"
        data-start-mode="suggest" data-caret="bar" data-highlight="solid"></script>

Some text to search

Every reed in a harmonica is a thin brass tongue riveted over a slot. When air flows, the reed swings through the slot and back, and that vibration is the note you hear. Bend a note and you change how the blow reed and draw reed share the airflow.
