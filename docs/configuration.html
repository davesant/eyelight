Configuration

Every option can be set with a data-* attribute on the script tag, or in a window.minisearchConfig object defined before the script runs. If both set the same option, the attribute wins.

<script>
  window.minisearchConfig = {
    prompt: 'search',
    include: 'article',
    exclude: '.comments, [data-minisearch-ignore]',
    ignoreKeys: ['j', 'k', '?'],     // your own single-key shortcuts
    labels: { close: 'Fermer' }
  };
</script>
<script src="minisearch.min.js" defer></script>

Options

OptionAttributeDefaultWhat it does
promptdata-prompt""Text shown before the idle cursor and in the box, e.g. "search".
includedata-includemain, [role=main]CSS selector for the parts of the page that are searched. If nothing matches, the whole body is searched.
excludedata-exclude[data-minisearch-ignore]Selector for areas inside include that are never searched.
noCapturedata-no-capture[data-minisearch-nocapture]Selector for areas where typing is never captured, such as a game or a custom widget.
indexdata-index/minisearch-index.jsonURL of the page index. Use false to skip it. The default path is relative to the domain root, so if your site lives in a sub-folder, set this (see sub-folders).
sitemapdata-sitemap/sitemap.xmlFallback if the index can't be loaded. Use false to skip it.
pages-nullYour own list of pages, [{url, title, description, keywords, headings}]. It's always merged in with the other sources.
themedata-themeautoauto, light or dark.
positiondata-positioncenterWhere the idle cursor sits: center, left or right.
minCharsdata-min-chars2How many characters are needed before page matches are highlighted.
maxSuggestionsdata-max-suggestions8The most page suggestions to show. 0 turns suggestions off.
ignoreKeysdata-ignore-keys""Keys that are never captured, e.g. "j,k,?". It's usually better to call preventDefault() in your own shortcut handlers, because Minisearch ignores any key you've already handled.
capturedata-capturetrueSet to false to turn off type-anywhere. Users can still click the hint to search.
hintdata-hinttrueSet to false to hide the idle cursor and button. Use this if you have your own search button that calls Minisearch.open().
mobileButtondata-mobile-buttonautoauto shows the floating button on touch-only devices. always shows it everywhere, and never hides it.
navigate--(url) => void. Use it for single-page apps that route their own links.
labels-EnglishVisible text and screen reader text, for translation. See below.
-data-manual-Don't start automatically. Call Minisearch.init(config) yourself.

Labels

You can override any of these in labels. {n}, {i}, {m} and {s} are placeholders.

hint, hintOff, input, suggestions, prev, next, mode, close,
captureOn, captureOff, helpSuggest, helpPage, helpTouch,
total ("{n} on page"), position ("{i} of {n}"), none, announce, closed

JavaScript API

CallWhat it does
Minisearch.open(query?)Opens the search, optionally with some text already in the box.
Minisearch.close()Closes the search and removes the highlights.
Minisearch.setTheme('light' | 'dark' | 'auto')Changes the theme, e.g. from your own theme switch.
Minisearch.setCapture(bool)Turns type-anywhere on or off, and remembers the choice.
Minisearch.reindex()Reloads the page index.
Minisearch.destroy()Removes Minisearch from the page completely.

With a bundler, use import { init } from '@davesant/minisearch'. init(config) returns the same API.

Styling

The component lives in a shadow root, so your CSS can't break it and its CSS can't leak into your site. You can style it in three ways.

1. CSS custom properties

minisearch-ui {
  --ms-bg: #fffaf0;      --ms-fg: #2b2118;
  --ms-muted: #6b5a48;   --ms-border: #b89f84;
  --ms-accent: #a4410e;  --ms-accent-fg: #fff;
  --ms-active: #f6e7d3;  --ms-subtle: #eadccb;
  --ms-mark: #ffd98a;    --ms-mark-fg: #2b2118;
  --ms-radius: 4px;      --ms-font: Georgia, serif;
  --ms-width: 36rem;     --ms-gap: 20px;
  --ms-shadow: none;     --ms-z: 1000;
}
/* Match your own dark mode switch */
html.dark minisearch-ui { --ms-bg: #1b1612; --ms-fg: #f3e9dc; /* … */ }

If you change colours, check that text still has at least 4.5:1 contrast against the background.

2. Parts

For anything else, these parts can be styled with minisearch-ui::part(name): hint, caret, prompt, panel, suggestions, suggestion, bar, input, count, button, footer.

3. Highlight colours

Matches on the page are painted with the CSS Custom Highlight API. Your own rules win over the defaults:

::highlight(minisearch)         { background-color: #c7f0d8; color: #000; }
::highlight(minisearch-current) { background-color: #1a7f4b; color: #fff; }

In Windows high contrast mode, the system Mark and Highlight colours are used automatically.
