Configuration

Every option can be set with a data-* attribute on the script tag, or in a window.minimarkerConfig object defined before the script runs. If both set the same option, the attribute wins.

<script>
  window.minimarkerConfig = {
    prompt: 'search',
    include: 'article',
    exclude: '.comments, [data-minimarker-ignore]',
    ignoreKeys: ['j', 'k', '?'],     // your own single-key shortcuts
    labels: { close: 'Fermer' }
  };
</script>
<script src="minimarker.min.js" defer></script>

Labels

You can override any of these in labels. {n}, {i}, {m} and {s} are placeholders.

hint, hintOff, input, suggestions, prev, next, mode, close,
captureOn, captureOff, helpSuggest, helpPage, helpTouch,
total ("{n} on page"), position ("{i} of {n}"), none, noPages,
announce ("{m} on this page. {s} pages suggested."),
announcePage ("{m} on this page."), closed

The default helpSuggest and helpPage text depends on startMode.

JavaScript API

CallWhat it does
Minimarker.open(query?)Opens the search, optionally with some text already in the box.
Minimarker.close()Closes the search and removes the highlights.
Minimarker.setTheme('light' | 'dark' | 'auto')Changes the theme, e.g. from your own theme switch.
Minimarker.setCapture(bool)Turns type-anywhere on or off, and remembers the choice.
Minimarker.reindex()Reloads the page index.
Minimarker.destroy()Removes Minimarker from the page completely.

With a bundler, use import { init } from '@davesant/minimarker'. init(config) returns the same API.

Styling

The component lives in a shadow root, so your CSS can't break it and its CSS can't leak into your site. You can style it in three ways.

1. CSS custom properties

minimarker-ui {
  --minimarker-bg: #fffaf0;      --minimarker-fg: #2b2118;
  --minimarker-muted: #6b5a48;   --minimarker-border: #b89f84;
  --minimarker-accent: #a4410e;  --minimarker-accent-fg: #fff;
  --minimarker-active: #f6e7d3;  --minimarker-subtle: #eadccb;
  --minimarker-mark: #ffd98a;    --minimarker-mark-fg: #2b2118;
  --minimarker-radius: 4px;      --minimarker-font: Georgia, serif;
  --minimarker-width: 36rem;     --minimarker-gap: 20px;
  --minimarker-shadow: none;     --minimarker-z: 1000;
  --minimarker-marker: #9be37a;  --minimarker-marker-current: #ffc233;
  --minimarker-marker-blend: multiply;
}
/* Match your own dark mode switch */
html.dark minimarker-ui { --minimarker-bg: #1b1612; --minimarker-fg: #f3e9dc; /* … */ }

If you change colours, check that text still has at least 4.5:1 contrast against the background.

2. Parts

For anything else, these parts can be styled with minimarker-ui::part(name): hint, caret (idle cursor), cursor (block cursor in the box), prompt, panel, suggestions, suggestion, empty, bar, input, count, button, footer, marks (the marker overlay).

3. Highlight colours

With the default highlight: 'marker', matches are drawn as marker strokes in an overlay, and your page's HTML is never changed. Set the colours with --minimarker-marker and --minimarker-marker-current (see above). Minimarker looks at your page's background colour: on light pages the strokes are multiplied onto the page so dark text shows through, and on dark pages they use screen blending with darker marker colours so light text stays readable. To set the dark-page colours yourself, style minimarker-ui[data-page=dark].

With highlight: 'solid', matches are painted with the CSS Custom Highlight API. Your own rules win over the defaults:

::highlight(minimarker)         { background-color: #c7f0d8; color: #000; }
::highlight(minimarker-current) { background-color: #1a7f4b; color: #fff; }

In Windows high contrast mode, the system Mark and Highlight colours are used automatically.
